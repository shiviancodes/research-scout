# NEXUS — Network-Driven Adversarial Intelligence System
## Master Overview Document

---

## Vision

NEXUS treats the entire financial market as a **living, causal knowledge graph** that is continuously perturbed by corporate events, macro shocks, and funding stress. Alpha is generated by predicting how perturbations propagate through the network *before* price reflects them.

The core thesis:

> Every corporate event is a network perturbation.
> Every network stress is an alpha signal.
> Every signal needs adversarial validation before capital is committed.

This is not a trading system with a graph bolted on. The graph *is* the system. Everything else — signals, risk, execution — derives from the network topology and its dynamics.

---

## Why This Is Different

| Conventional Quant System | NEXUS |
|---|---|
| Finds correlations | Models causal structure |
| Events = price catalysts | Events = network shocks with cascade effects |
| Risk is a position-level overlay | Risk is a network-topology property |
| Backtests signals | Adversarially destroys signals before trusting them |
| One model, one signal type | Multi-agent debate before every trade decision |
| Signals are independent | Signals are validated against causal graph structure |
| Human research loop | Continuous autonomous signal discovery and destruction |

## Algorithm Inventory

| Layer | Algorithms |
|---|---|
| Graph learning | GraphSAGE, Graph Attention Networks (GAT), node2vec, GCN |
| Contagion modeling | SIR/SEIR on graphs, Monte Carlo cascade, DebtRank |
| Regime detection | Hidden Markov Models, Bayesian Online Changepoint Detection (BOCPD) |
| Signal discovery | Transfer entropy, Granger causality, causal DAG (PC algorithm) |
| Adversarial validation | Harvey-Liu-Zhu multiple testing, cross-validated regime tests |
| Portfolio construction | Hierarchical Risk Parity, cvxpylayers (differentiable optimization) |
| Event mechanics | Float-adjusted market cap modeling, deal completion probability (XGBoost) |
| NLP | EDGAR parser, supply chain extractor, regulatory language shift detector |
| Execution | Market impact model (Almgren-Chriss), optimal order splitting |
| Alternative data | Satellite imagery CV, on-chain DeFi analytics, narrative clustering |

## Three Key Improvements (see `06_improvements.md`)

1. **Narrative Contagion Layer** — financial narratives spread before prices move; model both contagion networks simultaneously
2. **DeFi/Crypto Canary Layer** — on-chain stress precedes TradFi stress; fully transparent and free data
3. **Semiconductor Sector Focus First** — deep signal in a bounded, well-documented supply chain before expanding
